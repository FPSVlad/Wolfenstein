# Sky Slingers (Python fan game)

Оригинальная фан-игра в жанре физической рогатки, вдохновлённая классическими mobile puzzle-играми.

## Что есть

- рогатка + запуск персонажа по траектории;
- физика: гравитация, импульсы, столкновения;
- разрушаемые конструкции из блоков;
- цели, которые нужно выбить;
- несколько уровней;
- полностью свои визуалы и синтезированные звуки (без сторонних игровых ассетов).

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python3 main.py
```

## Управление

- Зажми `ЛКМ` на шаре и потяни — натяжка рогатки
- Отпусти `ЛКМ` — запуск
- `R` — рестарт уровня
- `N` — следующий уровень (после победы)
- `Esc` — выход
