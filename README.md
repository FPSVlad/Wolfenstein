# WolvenStorm 3D (fan game)

Небольшая браузерная фан-игра в духе Wolfenstein 3D:

- raycasting-рендеринг стен;
- миникарта;
- стрельба и цели;
- синтезированные звуки через WebAudio;
- полностью оригинальные текстуры/визуал (процедурная отрисовка).

## Запуск

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.
