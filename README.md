# BlockCraft Classic 2009 (fan game, Python)

Фан-игра на Python, вдохновлённая Minecraft Classic (2009):

- блочный 3D-мир с процедурной генерацией ландшафта;
- размещение/удаление блоков мышью;
- свои пиксельные текстуры (генерируются в коде);
- свои звуки (процедурно генерируются в `.wav`);
- управление от первого лица.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python3 main.py
```

## Управление

- `W/A/S/D` — движение
- `Space` — прыжок
- `Mouse` — обзор
- `LMB` — ломать блок
- `RMB` — ставить блок
- `1..7` — выбор типа блока
- `Esc` — выход

## Примечание

Это фан-проект с полностью оригинальными ассетами (пиксельные текстуры и звуки), не официальный продукт Mojang.
